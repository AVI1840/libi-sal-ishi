## 2. מה צריך לפני פיילוט

### קריטי (חוסם)

| פריט | מה נדרש | בעלים | זמן משוער |
|------|---------|-------|----------|
| הכרעת סל בסיס | מה חובה לכל משתתף | ביטוח לאומי + רווחה | שבועיים |
| הכרעת מודל תקציבי | מי משלם, איך | אוצר + משפטי | שבועיים |
| הכרעת תפקיד מתאמת | סמכויות, יחס, אחריות | רווחה | שבועיים |
| חיבור DB | PostgreSQL + persistence | צוות פיתוח | 2-3 שבועות |
| אונבורדינג 5 ספקים | הסכם, מחירון, רישום | מפעיל שטח + רכש | 3-4 שבועות |
| קליטת 50 אזרחים | intake אמיתי | מתאמות | 2-4 שבועות |

### גבוה (משפר משמעותית)

| פריט | מה נדרש | בעלים | זמן משוער |
|------|---------|-------|----------|

| אישור פרסונה | UI קיים, צריך backend | צוות פיתוח | שבוע |

| Feedback loop | שאלון אחרי שירות | צוות פיתוח | 2 שבועות |
| חיבור Frontend ↔ Backend | API calls אמיתיים | צוות פיתוח | 2-3 שבועות |
